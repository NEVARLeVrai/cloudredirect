# 🤝 Contributing to cloudredirect

## 🛠️ Improve the project

Pull requests are welcome. Describe the problem or improvement and how you verified the change. 

This repository is a fork of [crghofficial/cloudredirect](https://github.com/crghofficial/cloudredirect). Use this repository for fork-specific changes and the upstream project for general changes.

## 📜 Clone the repo

    git clone -b master --single-branch --recursive https://github.com/NEVARLeVrai/cloudredirect.git

## ✅ Verify your changes

Test changes with a dedicated directory and dummy save files. Describe the operating system and affected redirection behavior.

## 📬 Open a pull request

Keep the change focused and link the related issue when there is one. Include verification steps and screenshots for visual changes when applicable.
